# Homepage Images

Drop your images into this folder. They will be served from `/images/home/` and picked up automatically by the homepage.

## Required filenames

| File | Used on | Recommended size |
|------|---------|-----------------|
| `hero-woman.jpg` | Hero section — right column main photo | 900×950px |
| `feat-meal-plan.jpg` | Features — Meal Plan large card | 900×600px |
| `feat-fasting.jpg` | Features — Fasting Timer card | 700×500px |
| `feat-progress.jpg` | Features — Progress Tracking card | 700×500px |
| `meal-thumb.jpg` | Hero widget — meal preview thumbnail | 200×200px |

## Notes
- All images fall back to Unsplash placeholders automatically if the file is missing.
- Use JPEG format for photos (smaller file size).
- Optimize to &lt;300 KB per image for fast mobile loads.
