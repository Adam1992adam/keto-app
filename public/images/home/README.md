# Homepage Images

Drop your images into this folder. They will be served from `/images/home/` and picked up automatically by the homepage. If a file is missing, a beautiful Unsplash placeholder appears instead.

## Image slots

| File | Used on | Recommended size |
|------|---------|-----------------|
| `hero-woman.jpg` | Hero section — right column main photo | 900×950 px portrait |
| `meal-thumb.jpg` | Hero widget — meal preview thumbnail | 200×200 px square |
| `feat-meal-plan.jpg` | Features — Meal Plan large card | 900×600 px |
| `feat-fasting.jpg` | Features — Fasting Timer card | 700×500 px |
| `feat-progress.jpg` | Features — Progress Tracking card | 700×500 px |
| `feat-habits.jpg` | Features — Daily Habits card | 700×500 px |
| `feat-shopping.jpg` | Features — Smart Shopping card | 700×500 px |
| `step-1.jpg` | How it works — Step 01 "Tell us about you" | 800×600 px |
| `step-2.jpg` | How it works — Step 02 "Get your plan" | 800×600 px |
| `step-3.jpg` | How it works — Step 03 "Show up daily" | 800×600 px |

## Notes
- All images fall back to Unsplash placeholders automatically if the file is missing.
- Use JPEG format for photos (smaller file size).
- Optimize to under 300 KB per image for fast mobile loads.
